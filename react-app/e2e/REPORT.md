## 2. Real data, no placeholders

Every screen was scanned for 13 forbidden patterns: `NaN`, `undefined`, the
prototype's bracketed placeholder copy (`[dose from record]`, `[page]`, …),
`lorem ipsum`, the prototype template syntax (`<sc-for`, `{{`,
`hint-placeholder`), and the five fabrications removed in earlier rounds —
`Kavitha`, `Year 3`, `1,284`, `Dr. Anitha`, `Corpus v2.4`, `awaiting sign-off`.

**Zero hits across 400 render checks.**

The matcher is word-bounded and case-correct. An earlier version used a
case-insensitive substring and flagged the formulation **"Nandukkal Parpam"**
as a rendered `NaN`. That was the harness, not the screen; `NaN` and
`undefined` are now matched case-sensitively with word boundaries.

Each screen was additionally asserted to have rendered more than chrome
(>40 characters of body text) and to show no error state.

## 7. The four clinical rules

All re-measured in the browser, not asserted from source.

| Rule | Measurement |
|---|---|
| **Dosha digits final on frame one** | First painted frame `100%/0%/0%/100%`, identical at rest. Min opacity **1** throughout — the digits never fade |
| **Rings sweep, digits do not** | Motion: `strokeDashoffset 100,100,100 → 10,100,100`. The ring animates; the number it sits beside does not |
| **Reduced motion is static** | Rings `0,100,100 → 0,100,100` — no change. Digits still settled at frame one |
| **Verdict opacity 1, scale only** | Badge opacity 1, card opacity 1 throughout. Transforms are `matrix(0.9,0,0,0.9,0,0) → matrix(0.907,0,0,0.907,0,0)` — uniform scale, no translate, no fade |
| **Heavy-metal bar unfilled** | Track present and `borderStyle: dashed`, exactly one child of width `2px` (the ceiling marker, not a fill). Label: *"No measured value. The ceiling of 30 milligrams per day is marked at the end of the track."* |

A verdict that fades in is a verdict a clinician can misread mid-transition; a
dosha percentage that counts up is a different reading of the patient than the
one the engine produced. Both are measured here rather than trusted.

**All 14 defined `@keyframes` blocks are used.** Two of them — `smDraw` and

`stroke-dashoffset 1` to `0`, and the counter-rotating kolam group's transform
changes between two samples a second apart.

`smDraw` was the last genuinely unused block. It now drives the self-drawing
herb line-art on the landing hero (10 paths) and the login aside (5 paths),
copied from the prototype with its original stagger. Under reduced motion there
is no dash array at all and the stroke is complete on first paint.

## Harness notes

`e2e/lib.mjs` is the single source of truth for the screen list, role matrix,
accounts and forbidden-text patterns. `roundC.mjs` launches **one browser per
phase**: a single headed Chrome held open across ~30 contexts died mid-sweep
with *"Target page, context or browser has been closed"* and took every later
suite with it. Per-phase launches contain a crash to the phase it happens in.

Three harness defects were found and fixed while building this suite, each of
which would otherwise have been reported as an application bug:

1. the `NaN` substring match on "Nandukkal Parpam" (§2)
2. a regex that read `animation: reduce ? undefined : 'smScale …'` and reported
   a missing keyframe named `reduce` — that line *is* the reduced-motion guard
3. `Number("1px")` → `NaN` → silently read as "fully drawn" when measuring
   `stroke-dashoffset`; now `parseFloat`
